# #0006 Razorpay Partner OAuth is unavailable within the deadline. Partner signup itself IS self-serve and explicitly welcomes 'individuals and students', but OAuth client_id/client_secret requires TECHNOLOGY PARTNER status, which is not self-serve: all partners onboard as Service Partners by default, the type-switch request is evaluated manually and the docs state 'this process can take around 2 to 3 weeks', with full KYC on approval. Deadline is ~2 weeks out. Sub-merchant accounts also default to Activation Status 'Not Submitted' and the documented path requires reaching 'Activated'. Therefore Q5 option (a) Partner Auth is dead for this submission; fall back to single test account with merchant_id as logical tenancy, declared openly.

Partner Auth with X-Razorpay-Account is named in the trade-off table as the right production answer and in the limitations list as what this build does not do, so the gap is stated rather than hidden.
