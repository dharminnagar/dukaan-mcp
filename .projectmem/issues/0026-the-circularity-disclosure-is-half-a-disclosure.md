# #0026 THE CIRCULARITY DISCLOSURE IS HALF A DISCLOSURE: it covers the adversarial transcripts and says nothing about the benign ones, and the benign side has exactly the same problem. Noticed 2026-08-26 while verifying the #0023 near-boundary work. The report currently discloses that all 35 adversarial transcripts carry origin 'hand' and were authored by the same person who wrote the gate rules, which is honest. But the 140 benign transcripts, including the 27 new near-boundary ones, were authored the same way by the same process. So 'the gate allowed every one of 132 near-boundary checkout steps' measures agreement between two things the same author wrote: the rules, and the definition of what legitimate shopping looks like at the edge of those rules. It is the identical logical shape as 'the gate caught every attack I designed to be catchable', and issue #0010 exists precisely because that shape is a liability rather than a result. CONSEQUENCE FOR THE HEADLINE CLAIM: the false-positive figure is now interpretable (0.00 over 200 benign steps, 132 of them near-boundary) but it is not yet independent. A reader who accepts the adversarial circularity caveat should apply it to the benign number too, and if the README discloses one and not the other that asymmetry is itself a tell. SCOPING CONSEQUENCE FOR THE PENDING LLM BATCH, and this is the actionable part: the model-generated batch must produce BENIGN transcripts as well as adversarial ones. #0010 and the DUK-18 ticket both describe the generator as producing adversarial sessions only. If it also produces benign sessions from the same context — the MCP tool schema and the merchant policy JSON, never the gate implementation — then 'the gate allowed N of M sessions an independent model considered legitimate' becomes a real false-positive measurement rather than a self-consistency check, and the report's existing per-origin breakout starts carrying both halves. That single scope change converts the most-doubted number in the submission into the best-supported one. ACTION: widen the LLM generator scope to benign plus adversarial before building it, and until then have the report disclose the benign circularity in the same sentence it discloses the adversarial one.
