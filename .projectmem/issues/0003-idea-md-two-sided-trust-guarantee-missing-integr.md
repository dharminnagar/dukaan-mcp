# #0003 IDEA.md 'two-sided trust guarantee / missing integrity primitive that ACP and x402 are still figuring out' is FALSE. ACP checkout spec (stable 2026-04-17) already makes the merchant authoritative: every checkout_sessions create/update returns full authoritative cart state, so the agent never transacts on cached price. ACP also already has a Product Feed Spec (item_id, price, availability, eligibility flags, gzipped JSONL/CSV/XML, 15-min refresh). Also a category error: x402 is M2M micropayments for API access, not catalogs; AP2 is payment authorization only; NPCI UAP is 'Unified Agent Protocol' (agent identity/authorization, still pre-RBI-approval), not catalog discovery.
