# #0005 BLOCKER: a headless agent cannot AUTHORIZE a payment on a vanilla Razorpay test account. Every documented server-to-server route is gated. S2S Redirect and S2S JSON v1/v2 all carry a 'raise a request with our Support team to get this feature enabled' block, and S2S generally requires PCI-DSS certification. UPI Collect (the server-side VPA flow, success@razorpay) was DEPRECATED 28 Feb 2026 per NPCI — new users must use UPI Intent. UPI Payment Links are explicitly not supported in test mode. Smart Collect test payments are Dashboard-button-only. Standard Checkout in test mode requires clicking a mock bank page and entering an OTP in a browser. Capture is NOT the problem (auto-capture is the account default and applies to Orders-API payments); AUTHORIZATION is. Only documented headless simulate-payment endpoint is POST /v1/bharatqr/pay/test, and BharatQR itself needs a support ticket to activate.
